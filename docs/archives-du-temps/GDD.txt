LES ARCHIVES DU TEMPS
GAME DESIGN DOCUMENT (VERSION CLAUDE)

====================================================
1. VISION DU PROJET
====================================================

Les Archives du Temps est un jeu d’enquête multijoueur inspiré du Cluedo, d’Indiana Jones, de Tomb Raider et d’Uncharted.

Le jeu repose sur une idée simple : un artefact historique a disparu des Archives du Temps, une organisation secrète chargée de protéger les objets les plus importants de l’Histoire.

Les joueurs doivent enquêter, explorer, interroger des PNJ, collecter des indices et formuler des hypothèses afin de découvrir la vérité.

Contrairement au Cluedo classique :
- il n'y a pas nécessairement de meurtre ;
- les enquêtes sont générées dynamiquement ;
- les motivations changent ;
- les suspects changent ;
- les artefacts changent ;
- les indices changent.

Objectif principal : créer un jeu hautement rejouable où chaque partie raconte une nouvelle aventure.

====================================================
2. UNIVERS
====================================================

Les Archives du Temps sont un immense complexe hors du temps.

L'organisation protège les reliques les plus importantes jamais créées par l'humanité.

Chaque aile des Archives est consacrée à une civilisation.

Zones principales :
- Égypte Antique
- Grèce Antique
- Empire Romain
- Civilisation Maya
- Moyen Âge
- Renaissance
- Révolution Industrielle
- Futur

Ces lieux sont accessibles via une grande carte mondiale servant de hub principal.

====================================================
3. BOUCLE DE JEU
====================================================

1. Génération de l'enquête
2. Exploration
3. Collecte d'indices
4. Déduction
5. Accusation finale
6. Résolution

Une enquête est générée à partir de :
- un artefact disparu ;
- un suspect ;
- un lieu ;
- un mobile ;
- une série d'indices.

- Collectionneur
- Agent Temporel

LIEU
Exemples :
- Temple Égyptien
- Bibliothèque Grecque
- Forge Médiévale

- Laboratoire Futuriste

MOBILE
Exemples :
- Appât du gain
- Recherche du pouvoir
- Vengeance
- Protection de l'Histoire

====================================================

- histoire ;

14. VISION LONG TERME
====================================================

Les Archives du Temps doit devenir une plateforme d'enquêtes génératives où chaque partie raconte une histoire différente.

Le joueur ne résout pas simplement une énigme.

Il voyage à travers les grandes civilisations de l'Histoire afin de préserver la mémoire du monde.
